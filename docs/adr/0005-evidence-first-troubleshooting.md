# ADR-0005 — Evidence-first troubleshooting

## Status

Accepted — Sprint 0, 2026-09-21.

## Context

Causa sugerida por LLM não é prova.

## Decision

Sintoma -> topologia -> hipóteses -> coleta/correlação -> validação -> candidatos/confiança -> recomendação. Findings exigem evidências.

## Consequences

Não há diagnóstico concreto nesta sprint; futura conclusão terá trilha verificável.

## Alternatives Considered

Gerar causa primeiro e buscar confirmação criaria viés e afirmações sem suporte.

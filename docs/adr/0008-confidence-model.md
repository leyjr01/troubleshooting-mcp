# ADR-0008 — Confidence model

## Status

Accepted — Sprint 0, 2026-09-21.

## Context

Percentual sem cálculo reproduzível sugere precisão inexistente.

## Decision

LOW/MEDIUM/HIGH qualitativos com rationale e seis dimensões explícitas. HIGH exige suporte independente e contradições reconciliadas.

## Consequences

Modelo valida estrutura, não calcula confiança. Responsável deve justificar; similaridade histórica não comprova runtime.

## Alternatives Considered

Escala numérica arbitrária ou contagem simples de logs duplicados não é aceita.

# Local knowledge ingestion

No new packages are required. The Git adapter needs an installed Git executable.
Load the local server configuration plus one knowledge overlay, set enabled=true
and replace its local_path with a reviewed source directory. Paths resolve against
the process working directory. Sources are never automatically cloned or fetched.

Public MCP search does not ingest. Prepare the index explicitly in the same process
before serving (or call refresh from an administrator-owned application flow):

```python
from pathlib import Path
from agt_mcp.configuration.loader import load_configuration
from agt_mcp.core.execution import ToolName
from agt_mcp.mcp.bootstrap import build_runtime
from agt_mcp.mcp.context import create_context

configuration = load_configuration(
    [
        Path("config/server/local.example.yaml"),
        Path("config/knowledge/local-git.example.yaml"),
    ]
)
runtime = build_runtime(configuration)
context = create_context(configuration, ToolName.SEARCH_INTERNAL_KNOWLEDGE, "demo", None)
# Inside the application's async entry point, after enabling/configuring this source:
# result = await runtime.knowledge.refresh("internal-git", context)
# server = create_server(runtime)  # same Runtime instance, with populated index
```

The default CLI server starts with an empty process-local index. Its searches return
no matches until its Runtime's service is explicitly populated. No separate ingestion
process persistence or background worker is promised in this sprint.

Supported formats: .md, .txt, .yaml, .yml, .json. Markdown front matter accepts only
KnowledgeMetadata fields. Safe YAML rejects custom tags, anchors, aliases and duplicate
keys. Heading hierarchy survives chunking; code-fence headings do not split sections.
Small sections remain intact rather than being dropped to meet minimum_size.

| Setting | Default |
| --- | --- |
| max_document_bytes | 65536 |
| max_documents | 200 |
| max_chunk_size / overlap / minimum_size | 1200 / 100 / 40 characters |
| max_chunks_per_document | 100 |
| max_total_chunks_per_ingestion | 2000 per source refresh |
| max_top_k | 10 |
| max_result_bytes | 32768, also bounded by request envelope |

Refresh reports new/changed/unchanged/deleted. Unchanged documents avoid embedding
calls; commit provenance is refreshed. Changed/deleted documents replace/remove stale
chunks. Invalid input leaves the prior complete index intact. rebuild=True reconstructs
the source index; constructing a new service rebuilds all derived state from scratch.
KnowledgeIndexManifest schema 1.0.0 records revision/branch, document checksums,
chunk IDs, provider identity, pipeline version/settings digest and creation time.

Fixtures are generated by tests/knowledge_support.py in temporary real Git repositories:
payments architecture, APIcast 503 runbook, TLS known error, PROD-only runbook,
malicious instructions, all five formats, paraphrased 2.16 documentation and two
fictional incidents with similar symptoms but different historical causes.
No full official documentation page is copied and no network access is required.
